# apple-and-orange

[Original practice problem](https://www.hackerrank.com/challenges/apple-and-orange/problem)

Date: 2026-11-09 (Asia/Kolkata). Status: **Accepted**. Platform: **HackerRank**.

## Approach

The approach iterates through the lists of apple and orange distances, calculates the final landing position by adding the distance to the tree's location, and checks if the position falls within the inclusive range [s, t]. Time complexity is O(m + n) where m and n are the number of apples and oranges, and space complexity is O(1) beyond the input storage.
