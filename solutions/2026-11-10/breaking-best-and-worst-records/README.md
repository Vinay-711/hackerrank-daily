# breaking-best-and-worst-records

[Original practice problem](https://www.hackerrank.com/challenges/breaking-best-and-worst-records/problem)

Date: 2026-11-10 (Asia/Kolkata). Status: **Accepted**. Platform: **HackerRank**.

## Approach

The solution initializes the min and max records with the first game's score. It then iterates through the remaining scores, updating the records and incrementing counters whenever a score strictly exceeds the current max or falls below the current min. Time complexity is O(n) and space complexity is O(1).
