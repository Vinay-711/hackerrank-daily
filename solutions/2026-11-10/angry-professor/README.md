# angry-professor

[Original practice problem](https://www.hackerrank.com/challenges/angry-professor/problem)

Date: 2026-11-10 (Asia/Kolkata). Status: **Accepted**. Platform: **HackerRank**.

## Approach

The solution iterates through the list of arrival times and counts how many students arrived at or before time 0. If the count is less than the threshold k, the class is cancelled (YES), otherwise it proceeds (NO). Time complexity is O(n) per test case, and space complexity is O(1) beyond the input storage.
