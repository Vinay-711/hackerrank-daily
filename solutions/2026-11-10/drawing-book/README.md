# drawing-book

[Original practice problem](https://www.hackerrank.com/challenges/drawing-book/problem)

Date: 2026-11-10 (Asia/Kolkata). Status: **Accepted**. Platform: **HackerRank**.

## Approach

The number of page turns from the front is calculated as p / 2. The number of page turns from the back is calculated as (n / 2) - (p / 2). The result is the minimum of these two values. This approach is O(1) time and O(1) space.
