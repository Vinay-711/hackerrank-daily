## Approach

The problem requires finding the maximum height among all hurdles. If the maximum height is greater than the character's natural jump height k, the number of doses needed is (maxHeight - k). Otherwise, the character needs 0 doses. The time complexity is O(n) to iterate through the list once, and space complexity is O(1) beyond the input storage.
