# bon-appetit

[Original practice problem](https://www.hackerrank.com/challenges/bon-appetit/problem)

Date: 2026-11-10 (Asia/Kolkata). Status: **Accepted**. Platform: **HackerRank**.

## Approach

The approach calculates the sum of all items in the bill, subtracts the item Anna did not eat (at index k), and divides the result by 2 to find the fair share. If the charged amount b equals the fair share, it prints 'Bon Appetit'; otherwise, it prints the difference. Time complexity is O(n) to sum the bill, and space complexity is O(1).
