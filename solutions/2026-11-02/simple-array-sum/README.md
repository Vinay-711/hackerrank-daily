# Simple Array Sum

Problem: https://www.hackerrank.com/challenges/simple-array-sum/problem

AI-assisted archived practice in Java 8.

## Approach

Consume each array element once and add it to a running total. The maximum sum under the stated constraints fits in a signed 32-bit integer.

Complexity: O(n) time and O(1) auxiliary space.

## Verification

Sample, singleton, maximum-size/value array and deterministic random input, checked with Python arbitrary-precision addition.

Run `python3 test_solution.py` with a local JDK.
