# maxsubarray

[Original practice problem](https://www.hackerrank.com/challenges/maxsubarray/problem)

Date: 2026-11-16 (Asia/Kolkata). Status: **Accepted**. Platform: **HackerRank**.

## Approach

For the maximum subarray sum, I used Kadane's algorithm, which runs in O(n) time and O(1) space. For the maximum subsequence sum, I summed all positive integers. If all integers are negative, the maximum is the largest single element in the array, which handles both subarray and subsequence cases correctly.
