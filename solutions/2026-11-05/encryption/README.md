Date: 2026-11-05 (Asia/Kolkata). Status: **Accepted**. Platform: **HackerRank**.

## Approach

The approach involves removing spaces from the input string, calculating the grid dimensions (rows and columns) based on the square root of the length, and then iterating column-wise to build the encrypted string. Time complexity is O(L) where L is the length of the string, and space complexity is O(L) to store the grid and the result.
