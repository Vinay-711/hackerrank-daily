# Plus Minus

[Original practice problem](https://www.hackerrank.com/challenges/plus-minus/problem)

Date: 2026-11-01 (Asia/Kolkata). Status: **Accepted**.

## Approach

Count positive, negative and zero values and divide each count by n. Format every ratio to six decimal places.

## Complexity

O(n) time and O(n) buffered input space.
